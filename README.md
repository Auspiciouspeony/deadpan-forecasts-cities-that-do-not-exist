One deadpan weather forecast for a city that does not exist, written as a
single line of at most 160 characters: in Brume, the fog lifts by 9am and
reveals the mountain was never there. Highs of 14, lows of mild regret,
visibility improving to 10 km of nothing.

## Run it

```sh
python3 main.py
```

It writes the forecast to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set): one line, no trailing
newline, mode 0644. The text is fixed, so every run produces identical
output.
